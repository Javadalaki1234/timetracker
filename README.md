# برنامه ثبت ساعات کاری — نسخه اندروید

این مخزن برای ساخت خودکار APK با GitHub Actions آماده شده است.

## چطور APK بگیری؟ (خیلی ساده)

### مرحله ۱: ساخت مخزن در گیت‌هاب
1. برو به https://github.com/new
2. یک نام برای مخزن بگذار (مثلاً `time-tracker-android`)
3. گزینه **Public** را انتخاب کن
4. روی **Create repository** کلیک کن

### مرحله ۲: آپلود فایل‌ها
1. داخل مخزن جدید، روی دکمه **uploading an existing file** کلیک کن
2. همه فایل‌های داخل این پوشه را بکش و رها کن:
   - `main.py`
   - `buildozer.spec`
   - `README.md`
   - پوشه `.github` (و فایل داخل آن)
3. پایین صفحه روی **Commit changes** کلیک کن

### مرحله ۳: ساخت APK
1. بعد از آپلود، به تب **Actions** برو
2. روی workflow به نام **Build Android APK** کلیک کن
3. روی دکمه **Run workflow** کلیک کن و بعد **Run workflow** را تأیید کن
4. صبر کن تا ساخت تمام شود (معمولاً ۱۵ تا ۳۰ دقیقه طول می‌کشد)
5. وقتی سبز شد، روی همان اجرا کلیک کن
6. پایین صفحه بخش **Artifacts** را پیدا کن و فایل **TimeTracker-APK** را دانلود کن

### مرحله ۴: نصب روی گوشی
فایل ZIP دانلود شده را باز کن و APK داخل آن را روی گوشی نصب کن.

## نکات
- اگر ساخت خطا داد، در تب Actions روی اجرای ناموفق کلیک کن و لاگ را ببین.
- این روش رایگان است و نیازی به Docker روی کامپیوترت ندارد.
